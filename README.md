# Про себе

Невелика персональна сторінка про Марину Ярошенко. Зроблена на чистому HTML, без CSS — це домашнє завдання ДЗ 21.1.

## Що тут є

- `index.html` — головна сторінка з короткою інформацією про мене
- `pages/contact.html` — контакти
- `pages/gallery.html` — кілька фото
- `photo/` — папка із зображеннями

## Як подивитись

Відкрити `index.html` у будь-якому браузері.

# ДЗ 21.1 — HTML-сторінка «Про себе»

Персональна сторінка-візитка **Марини Ярошенко**, зроблена на чистому HTML (без CSS).

## 📄 Опис

Сайт про себе: коротка інформація, фотографія, захоплення та контакти.

## 🗂️ Структура проєкту

```
marina/
├── index.html          # головна сторінка з короткою інформацією
├── pages/
│   ├── contact.html    # сторінка з контактами
│   └── gallery.html    # сторінка із зображеннями
└── photo/
    ├── marina.jpg      # головне фото
    └── README.md
```

## ✅ Виконані вимоги

- Структурований проєкт: фото у папці `photo/`, додаткові сторінки у папці `pages/`
- Використано теги, що проходили на занятті (`header`, `nav`, `ul`/`ol`, `table`, `figure`, `img`, `a` тощо)
- **CSS не використовується**
- Роботу виконано в окремій гілці репозиторію: `dz-21.1`

## 🚀 Як переглянути

Відкрий файл `index.html` у браузері.
